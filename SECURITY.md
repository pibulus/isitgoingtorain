# Security

This app is a static, no-login, no-backend weather utility. It should not store secrets, collect
analytics, or cache live weather responses.

If you find a security or privacy issue, contact the maintainer through GitHub. Please include:

- what happened
- the browser/device used
- whether location permission, manual city lookup, install/PWA mode, or service worker caching was involved

Do not include precise private location data unless it is necessary to explain the issue.
